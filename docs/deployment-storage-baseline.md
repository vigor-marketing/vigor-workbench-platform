# 统一部署与存储基线

生效日期：2026-08-12

## 强制规则

1. 所有工作台及后续小程序只在腾讯云 CVM 实例部署和运行。
2. 所有业务资料文件（上传资料、产品文件、报价单、合同电子版、知识库附件、导出文件、归档附件）只存放在该实例对应的腾讯云 COS。
3. 不使用 CloudBase 作为应用运行环境、数据库、文件存储或身份服务。
4. 小程序只能由工作台同域路径 `/apps/<app-id>/` 访问；禁止使用 GitHub 页面、CloudBase 域名或第三方托管地址作为业务入口。
5. BFF、数据库及内部服务仅绑定实例本机地址，由 Nginx 代理；不得直接暴露内部端口。
6. 工作台可继续使用 IP 入口 `http://1.15.91.150/`；在 HTTP 环境中不得录入真实密码、客户、合同或财务敏感数据。

## 状态与资料的区分

- 系统状态（临时待办、队列、健康状态、审计索引）可存于实例本地受限目录，后续可迁移至实例内 PostgreSQL。
- 业务资料文件必须进入 COS，数据库只保存 COS 对象键、版本、校验值、文件位置和审计信息。
