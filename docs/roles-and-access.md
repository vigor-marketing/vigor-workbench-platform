# 角色与访问规则（首版基线）

| 角色 | 平台范围 | 首批应用 |
| --- | --- | --- |
| 总经理 | 全部经营数据 | 三个应用均可见 |
| 分管销售副总 / 销售总监 | 全部经营数据及销售明细 | 三个应用均可见 |
| 分管财务副总 / 财务总监 | 全部经营数据 | 三个应用均可见 |
| 销售经理 | 本销售组数据 | AI 销售陪练 |
| 销售员 | 本人客户与协作项目 | AI 销售陪练；产品编码器只读 |
| 采购经理 | 本采购组数据 | 产品编码器 |
| 财务经理 | 财务数据与用印审批 | 销售提成 |

销售明细的特别规则：仅总经理与分管销售副总可查看全部销售明细；其他人员须由 BFF 按组织、角色和数据归属过滤。

前端的菜单隐藏只改善体验，不能替代授权。每个 BFF API 和业务模块 API 都必须重复执行访问控制和审计。
