# 043 – 顶栏全局搜索（待办/应用/人员/菜单跳转）

## 需求
「搜索框没有意义只是图标」「方案一先做吧」——顶栏搜索图标原为摆设，改为真实可用的全局搜索。

## 实现
- 新组件 `src/components/GlobalSearch.tsx`（顶栏 .top-actions 内）：
  - 输入即搜，下拉按组展示：**菜单跳转 / 待办事项 / 应用模块 / 人员**（各最多 3 条）。
  - 范围：待办（当前列表，标题/来源，跳转按来源类型）；应用（仅当前岗位可访问，名称/描述）；人员（org 树，姓名/英文名/部门/小组/岗位，点击进组织架构页）；菜单（管理员项仅管理员可见）。
  - 交互：↑↓ 选择、Enter 跳转、Esc 关闭、点击外部关闭、清空按钮、**匹配词高亮**。
  - 人员数据首次加载拉取 `/api/org/tree`（登录会话）。
- 样式：`.global-search*`（250px 搜索框 + 430px 下拉 + 分组标签 + 激活高亮）；≤680px 隐藏。
- 顶栏原无功能搜索图标已移除。

## 验证（部署后）
- Playwright：搜索框存在；输入「待办」→ 菜单跳转组出现「我的待办」；「吴琼」→ 人员组命中；「提成」→ 应用模块组命中「销售提成」；↑↓+Enter 成功跳转 /workspace/apps/sales-commission；无 JS 报错。
- GLM 截图评审：下拉分组/条目/图标/说明整齐，无错位遮挡。
