## 重要边界

- 当前是 HTTP 内测环境。登录、用户及权限保存在浏览器 localStorage，仅用于演示，不能作为真实业务数据/正式身份认证。
- 当前权限控制仅覆盖“工作台入口与模块可访问性”；每个小程序内部的新增、修改、删除权限仍需后续逐一接入统一身份及接口鉴权，才能做到服务端强制控制。
- 未变更安全组、公开端口、数据库或 TLS/OIDC。若上线真实账号，必须先配置 HTTPS、服务端会话/OIDC、数据库持久化与审计。
