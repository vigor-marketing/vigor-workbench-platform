# 033 – 侧边栏悬停展开/移出折叠 + 个人账号以下导航图标重设计

## 需求
1. 鼠标在导航栏区域 → 侧边栏持续展开；鼠标移到工作区域 → 折叠侧边栏。
2. 个人账号及以下所有板块（个人账号/组织架构/账号与权限/岗位与权限/服务与授权/接入设置）图标设计优化。

## 改动

### 侧边栏交互（src/App.tsx）
- 移除原「点击汉堡按钮折叠/展开 + localStorage 记忆 + 点击导航自动展开后回折叠」逻辑。
- 新状态：`sidebarHover`（悬停展开）、`sidebarPinned`（点击汉堡固定）、`sidebarTimer`（移出后 250ms 延迟折叠，防抖动）。
- 桌面端（≥961px）：`sidebarCollapsed = !(hover || pinned)`；`<aside>` 绑定 `onMouseEnter/onMouseLeave`。
- 行为：
  - 默认折叠（72px 图标栏）。
  - 鼠标进入侧边栏 → 展开 246px，导航文字可见；点击导航项跳转后仍保持展开（鼠标还在侧边栏内）。
  - 鼠标移到工作区 → 250ms 后折叠回 72px。
  - 汉堡按钮（桌面）→ 固定/取消固定：固定后移出鼠标仍保持展开；取消固定后恢复悬停控制。
  - 移动端（≤960px）抽屉逻辑不变。
- 提交：`6e05c62`（功能）、`72d898a`（修复取消固定后误保持展开：toggleNav 不再强设 hover=true）。

### 图标（src/components/Icon.tsx + App.tsx 导航项）
新增 6 个线条图标（24×24、stroke 1.7，与现有风格统一）：
| 导航项 | 图标 | 语义 |
| --- | --- | --- |
| 个人账号 | `user` | 单人轮廓 |
| 组织架构 | `org` | 根节点+分支的组织树 |
| 账号与权限 | `users` | 双人（账号集合） |
| 岗位与权限 | `user-check` | 人+对勾（岗位授权） |
| 服务与授权 | `key` | 钥匙（授权凭据） |
| 接入设置 | `sliders` | 调节滑杆（配置接入） |

## 验证（部署后，Playwright + GLM-4V）
- 初始 72px → 悬停 246px → 移出 72px；悬停中点击「组织架构」正常跳转且保持展开；汉堡固定后移出仍 246px，取消固定后移出回 72px。
- 6 个导航项图标各不相同、风格统一、无缺失/重复；GLM 截图评审：图标与功能强关联、现代简洁。
- 无 JS 报错。
