# 039 – 采购部三组更名（采购一组/采购二组/质量组）+ 负责人置顶 + 全平台同步

## 需求
「采购是三个部门，采购一组采购二组质量组，各部门的负责人应该在第一位，所有的都同步」

## 改动
- **组名**：采购部小组 采购一单元→**采购一组**、采购二单元→**采购二组**（质量组不变）；顺序调整为 **采购一组、采购二组、质量组**。
- **BFF**（org.service.ts）：
  - seedFlat 组名同步更名（新装环境一致）。
  - teamRank：采购部 `一组/一单元→1、二组/二单元→2、质量→3`（兼容旧名）。
- **前端**：
  - 账号与权限（App.tsx）：采购部像销售部一样按小组分块展示；子分组只取该部门组织架构中存在的组（过滤历史残留如 V5），其余归「未分组」；组内/部门内**负责人（departmentHead）置顶**；部门头部显示**多个主管 chip**。
  - 组织架构图（OrgChartPage）：小组内人员按负责人优先排序（岗位含 经理/总监/总经理/副总/负责人/管理岗 者在前）。
- **数据（CVM）**：org.json 更名两小组；users.json 9 个采购账号补 department=采购部 + teamName（按 org 人员关联），负责人 徐振兴/张朋/乔婷 标 departmentHead=true；BFF 重启加载。
